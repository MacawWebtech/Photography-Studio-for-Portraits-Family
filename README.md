# Lumen Studio - Photography Studio HTML Template

A warm, easy-to-use website template for a portrait, family and maternity photography studio, with a client dashboard (bookings, proof galleries, favourites, print orders).

## Quick start
1. Unzip the folder.
2. Open `pages/index.html` in your browser. No build step needed (internet is required for Bootstrap, icons, fonts and placeholder photos from CDNs).
3. For a live site, upload the whole folder to any static host (Netlify, Vercel, GitHub Pages, shared hosting).
